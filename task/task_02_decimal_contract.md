## Цель

Задать единый контракт точных десятичных значений для ввода, API, хранения и итогов без потери дробной части.

## Ожидаемый результат

Создать `task/decimal_contract.md` с грамматикой, нормализацией, выбранным представлением, операциями суммирования и таблицей проверочных примеров.

## Объём работ

1. Сопоставить десятичные строки и точный decimal-тип с NumberField/SQLite и JavaScript hooks. Рекомендуемый технический подход: каноническая десятичная строка на границах API/хранилища и точная арифметика на Shelf; окончательный выбор обосновать до схемы.
2. Определить точку и запятую во вводе, пустое значение как ноль, пробелы, ведущие/концевые нули, знак, экспоненту, разделители тысяч и недопустимые NaN/Infinity. Не вводить произвольный предел масштаба, округление или максимум 999.
3. Отделить сохранение числового значения от оформления строки: например 1,50 может отображаться как 1,5, но число не изменяется. Для технического ограничения размера запроса определить явный отказ, не усечение.
4. Зафиксировать шесть полей из §11.3, итог строки, итоги по видам, итог назначений, итог замен, общий итог. Клиентский предпросмотр предварительный; ответ сервера окончательный.
5. Подготовить точные ожидаемые результаты для 0,1 + 0,2, 1,25, 1000,125, очень длинной дроби и большого целого за пределами точного JS Number.
