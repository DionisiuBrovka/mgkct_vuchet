## Объём работ

1. Повторно проверить git tracked/ignored и использования ресурсов/imports/scripts; не удалять файл только по названию или наличию autogenerated комментария.
2. Проверить back.jpg, неиспользуемый Assignment, uuid/json-пакеты и старые пути; удалять только при подтверждённом отсутствии использования, вместе с ссылками.

4. По архитектурному решению проверить необходимость Android/iOS/macOS/Linux/Windows оболочек; если Web-only подтверждено анализом, удалить неиспользуемые scaffolds и обновить build context. Самостоятельную поддержку native не добавлять.
5. Устранить машинозависимый .vscode путь и устаревшие ignore-исключения, сохранить исключение секретов/рабочих баз. Локальный service_account.json не читать, не коммитить и не удалять как якобы неиспользуемый ключ без отдельного подтверждения.
6. Проверить историю/индекс на факт случайно отслеживаемых секретов безопасным способом без вывода содержимого; при доказанной утечке зафиксировать отдельное действие владельца, историю Git не переписывать. Корневые DEPLOY/CLAUDE оставлять до переноса Task 27.

Это целевые команды зависимостей, а не существовавшие при аудите файлы.

```bash

git diff --check
```

Если команда или путь изменены выполненной зависимостью, сначала зафиксировать актуальную замену и причину, затем выполнить её. Ошибка окружения и пропуск обязательной проверки не означают успешную приёмку.
