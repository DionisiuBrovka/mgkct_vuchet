## Все месяцы — уточнение 2026-10-09

Добавлен пункт «Все месяцы» в фильтр месяца. Он показывает созданные отчёты
активных преподавателей за выбранный учебный год, отдельной карточкой на каждый
месяц, от новых к старым. На карточках указан период; переход использует период
конкретного отчёта. Поиск и статус применяются совместно на Shelf.

API дополнен вариантом `GET /api/admin/reports?academicYear=Y`; сочетать его
с календарными `year/month` нельзя. Обычный месячный список по-прежнему показывает
также преподавателей без сохранённого отчёта. Контракт обновлён.

Серверный интеграционный тест проверяет границу календарных лет, исключение
соседних учебных лет, фильтры, пустую выдачу, запрет доступа преподавателю и
неверные параметры. Widget-тест выбирает «Все месяцы» и открывает январский
отчёт следующего календарного года.

Тестовый стенд обновлён с сохранением тома. HTTP-проверка подтвердила четыре
карточки за сентябрь/октябрь 2026 и доступность соответствующих отчётов.
Браузерная проверка по-прежнему оставлена владельцу.
