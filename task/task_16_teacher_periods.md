## Цель

Показать учителю месяцы и статусы текущего учебного года по серверной политике с устойчивым состоянием загрузки.

## Ожидаемый результат

Состояние списка месяцев, серверные периоды, refresh/retry и маршрутизация к собственному отчёту.

## Объём работ

1. Убрать окончательный расчёт текущего учебного года из UI, использовать periods/statuses DTO и локализованные подписи.
2. Перенести запросы из State в согласованный state layer, отделить loading/data/empty/error и предотвращать применение устаревшего ответа.
3. Применить согласованную августовскую политику; ручного выбора года у teacher не добавлять.
4. После возвращения из формы обновлять статусы; сохранять понятные подсказки для draft/submitted/confirmed и переход только в допустимый сервером период.
5. Добавить тесты дат на границах через API fixtures, retry и обновления после submit/return; изменённые часы компьютера не меняют доступность периода.

## Что не входит в задачу

Часы формы и замены, выбор года преподавателем.

Общие исключения продукта: комментарии/история, экспорт/печать, массовое подтверждение, клиентская админка и офлайн-синхронизация.
