# Установка Debian 13 — 2026-10-09

## Реализация

Входная команда: `sudo bash scripts/deploy.sh debian`.
Нативный режим добавлен по запросу владельца; контейнерный режим сохранён.

- Debian 13 amd64/systemd preflight, блокировка параллельного запуска.
- APT-зависимости, закреплённые Flutter 3.44.8/Dart 3.12.2/PB 0.40.1.
- SHA-256 архивного SDK взят из официального releases_linux.json;
  PocketBase проверяется существующим скриптом загрузки.
- Сборка отдельным пользователем без доступа к секретам и рабочей базе.
- Отдельные systemd users для Shelf и PB, readonly-код, PB только loopback.
- Первичный администратор приложения, случайные пароли в root-only файлах.
- Повторный запуск сохраняет пароли и данные; перед миграциями остановленные
  данные и конфигурация архивируются. Код хранится отдельными выпусками.
- При отказе обновления нет автоматического сброса/отката базы. Диагностика,
  повторный запуск и согласованное восстановление описаны в README.
