## Цель

Завершить сценарий добавления, редактирования и удаления замен по ID в составе месячного отчёта.

## Ожидаемый результат

Общий add/edit диалог с date control, description и точными часами; стабильные ID, тесты формы и сохранения.

## Объём работ

1. Заменить текст 'Группа' единым описанием того, кого и в какой группе заменяли; не разделять на relations.
2. Реализовать создание и редактирование, сохраняя ID существующей замены; новые ID и их преобразование брать из API contract.
3. Добавить удобный русский выбор/ввод даты внутри выбранного месяца; местная проверка помогает пользователю, окончательная дата проверяется Shelf.
4. Использовать точный input contract часов, локальные предварительные суммы и сохранность при ошибке; cancel не меняет исходную замену.
5. Удалять только выбранный ID даже при полностью одинаковом содержимом/дне; все операции до save/submit остаются в локальном агрегате.
6. Проверить весь сценарий отчёта только с заменами, readonly после submit/confirm и повторное редактирование после return.
